# Smart Bazaar landing page

A responsive, static storefront landing page inspired by Amazon's broad e-commerce layout, using the fictional brand **Smart Bazaar**.

## Run
Open `index.html` in a browser. No build step and no JavaScript are required.

## Layout choices
- **Flexbox:** header/navigation, hero actions, benefit items, card content, footer links.
- **CSS Grid:** hero/page composition, benefits, category gallery, feature cards, footer columns.
- **Responsive breakpoints:** tablet at 900px and mobile at 600px.
- Semantic landmarks, accessible labels, skip link, descriptive image alt text, metadata and CSS custom properties are included.
